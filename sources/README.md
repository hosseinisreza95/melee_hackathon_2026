# Source use rules
1. Prefer official sources.
2. Register every source in `data/source_registry.csv`.
3. Respect authentication, geographic restrictions, licences and rate limits.
4. Do not scrape when an official API/download exists.
5. Do not redistribute restricted raw data; commit collection code instead.
6. Retain source URL and timestamp for every assertion.
7. If conditions are unclear, use an organizer-provided frozen extract.
8. No result is not proof of no registration.

Verify starter EPPO candidates before changing `mapping_status` to `validated`.
