# Quick start for participants

## Before coding
1. Read the challenge brief, this README and `sources/README.md`.
2. Confirm three sources, two regions and pilot products.
3. Test source access; use organizer-provided frozen extracts if necessary.
4. Copy `.env.example` to `.env`; never commit secrets.
5. Run `python scripts/validate_data.py`.
6. Review `schema/openapi.yaml` and `data/field_dictionary.csv`.
7. Decide the Microsoft 365 integration path.

## Recommended first hour
- Assign data, AI, application, integration and presentation owners.
- Complete one source end to end before adding others.
- Store evidence before normalization.
- Return sources and validation status in the first user-facing answer.
- Run the evaluator early.

## Blocked source
Do not bypass authentication, geography, rate limits or technical controls. Record the failure, use the supplied frozen extract and disclose the limitation.
